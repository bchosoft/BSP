# Bcho Suite Pro 2.5.5

## Español

Herramientas de escritorio para presets, bibliotecas y pedales TONEX de IK Multimedia.

- **Conversor TX2P a TXP clásico:** muestra bloques y rutas paralelas, permite elegir una rama, conservar efectos compatibles y distinguir Activo, Bypass y Excluir. Resuelve los modelos externos y los incorpora al TXP; si falta un modelo necesario, impide generar un archivo incompleto. Las funciones exclusivas de TONEX Rig no se trasladan al formato clásico.
- **Bibliotecas:** importación, extracción, conversión y fusión de Library.db clásico y Library2.db de TONEX 2.0. Conserva Library2.db junto a su carpeta Library.
- **USB Pedal I/O y editor:** lectura, copia de seguridad, restauración y edición de presets en dispositivos compatibles. Los cambios en vivo pueden afectar inmediatamente al pedal; revisa el dispositivo y el slot activo y guarda una copia antes de escribir.
- **Editor de archivos:** ajustes de efectos, amplificador y pantalla; controles organizados y filas centradas.
- **NAM a TONEX:** motor integrado, comparación A/B y escucha con interfaz de audio. Incluye tres clonados gratuitos; el registro de esta sección es independiente.
- Interfaz en diez idiomas, caracteres corregidos y animaciones LED que respetan los bordes y el orden de las opciones.

Cada ZIP incluye la aplicación y **diez manuales PDF nuevos**, uno por idioma: ES, EN, GL, CA, EU, PT, IT, FR, DE y RU.

### Descargas

[Windows x64](https://github.com/bchosoft/BSP/releases/download/v2.5.5/Bcho-Suite-Pro-Windows-x64-v2.5.5.zip)

Extrae el ZIP completo antes de abrir la aplicación. En Windows conserva Bcho-Suite-Pro.exe junto a BchoSuiteNamEngine.dll; se necesita el runtime Microsoft Edge WebView2. En macOS conserva la aplicación .app completa. En Linux conserva el ejecutable junto a libBchoSuiteNamEngine.so y utiliza una distribución con GTK 3 y WebKitGTK 4.1. Lee el manual de tu idioma dentro de MANUAL.

TONEX ONE+ continúa en pruebas y la aplicación avisa antes de leerlo. La conversión de archivos TONEX Board no implica compatibilidad USB con TONEX Board. El reemplazo de pantalla puede comportarse de forma distinta según el dispositivo; consulta las limitaciones del manual. Cierra TONEX antes de modificar su biblioteca y conserva copias de seguridad.

La aplicación no requiere herramientas de desarrollo para utilizarse. Este repositorio público ofrece documentación y paquetes de distribución, sin código fuente de la Suite.

Usa estas herramientas únicamente con contenido para el que dispongas de autorización. TONEX es una marca de IK Multimedia; Bcho Suite Pro es una herramienta independiente.

## English

Desktop tools for IK Multimedia TONEX presets, libraries and compatible pedals.

- **TX2P to classic TXP converter:** displays blocks and parallel paths, keeps one branch and compatible effects, and distinguishes Active, Bypass and Exclude. It resolves external models and embeds them in the TXP; missing required models block incomplete exports. TONEX Rig-only features cannot be transferred to the classic format.
- **Libraries:** import, extract, convert and merge classic Library.db and TONEX 2.0 Library2.db. Keep Library2.db with its Library content folder.
- **USB Pedal I/O and editor:** read, back up, restore and edit presets on supported devices. Live changes can affect the pedal immediately; check the device and active slot and back up before writing.
- **File editor:** effects, amplifier and cabinet controls with organized, centered rows.
- **NAM to TONEX:** integrated engine, A/B comparison and listening through an audio interface. Three free clones are included; registration for this section is separate.
- Ten interface languages, corrected characters and LED animations that follow card borders and visual order.

Every ZIP includes the application and **ten new illustrated PDF manuals**, one per language: ES, EN, GL, CA, EU, PT, IT, FR, DE and RU.
